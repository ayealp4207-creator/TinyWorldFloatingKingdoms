# Tiny World – Floating Kingdoms

A Godot 4 mobile 3D strategy and exploration game.

## Phase 1
- Floating island prototype
- Touch-friendly orbit camera
- Resource collection foundation
- Building placement foundation
- Data-driven level progression

## Requirements
- Godot 4.x
- Android export templates for APK/AAB builds

## Project status
Initial project scaffold is being prepared. Gameplay systems and Android builds must be tested in Godot before release.
