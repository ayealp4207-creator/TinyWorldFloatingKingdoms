# Development Roadmap

## Stage 1 — Playable prototype
- [x] Godot 4 project scaffold
- [x] Procedural floating island placeholder
- [x] Orbit camera controls for mouse and touch
- [x] Tap-to-collect wood and stone placeholders
- [x] Starter level data file
- [ ] Test in Godot Editor and Android device
- [ ] Add building placement and level objective UI

## Stage 2 — Gameplay and 100 levels
Economy, production chains, quests, island unlocks, and data-driven progression.

## Stage 3 — Visual and audio polish
Replace placeholders with optimized models, animations, materials, sound, and effects.

## Stage 4 — Full systems
Save/load, Turkish and English localization, settings, achievements, rewards, and optional ads.

## Stage 5 — QA and optimization
Test progression, saves, aspect ratios, memory use, and performance on target Android devices.

## Stage 6 — Android release
Configure package ID and signing, export APK/AAB, prepare store assets and privacy disclosures.

## Current limitations
This is a code scaffold, not a verified Android build. Open with Godot 4.x, run the main scene, fix any editor/runtime issues, and test on a device before treating it as release-ready.
